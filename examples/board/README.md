# Board example

This vertical project explains tscircuit's `<board>` element with verified PCB and 3D imagery generated by `tsci`, functional measurements, captions, and one real Neovim recording captured by VHS. The editor scrolls through the sandboxed source, types the silkscreen element with native indentation and cursor behavior, saves it, and keeps the verified board result visible below. The pipeline rejects the capture declaration unless its starting and final buffers match the authored code.

```sh
bun run video validate examples/board/video.ts
VIDEO_FAKE_VOICE=1 bun run video render examples/board/video.ts
```

The fake voice is only for deterministic pipeline development. A release-quality run should configure the local Chatterbox worker described in the root limitations document.
