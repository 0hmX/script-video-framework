# tscircuit for KiCad People — Episode 1

Long-form, manual-first introduction to installing the tscircuit CLI, understanding its command surface, and initializing a project.

The canonical narration and per-beat visual plan live in `script.ts`; the Markdown file in `docs/series/tscircuit-for-kicad-people/` is the readable episode outline. Terminal footage is captured from real commands with VHS. The project renders in the standard YouTube 16:9 frame at 1920×1080.

```sh
bun run video validate examples/kicad-people-01/video-1080p.ts --json
bun run video render examples/kicad-people-01/video-1080p.ts --json
```
